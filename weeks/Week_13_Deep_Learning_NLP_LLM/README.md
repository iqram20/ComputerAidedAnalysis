## Learning Objectives

By the end of this week, students should be able to:

- explain the difference between traditional machine learning and deep learning;
- describe the basic structure of a neural network;
- identify common engineering applications of neural networks;
- explain the purpose of activation functions;
- build a simple neural-network regression example;
- explain basic NLP concepts;
- convert engineering text to numerical features using TF-IDF;
- train a simple text classifier;
- explain at a high level how transformers and LLMs work;
- identify useful engineering applications of LLMs;
- recognize hallucination, validation, privacy, and safety concerns;
- explain when an LLM should and should not be trusted.
