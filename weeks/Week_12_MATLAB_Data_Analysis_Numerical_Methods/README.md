## Learning Objectives

By the end of this week, students should be able to:

- import CSV and Excel data for computational analysis;
- work with tabular engineering data;
- calculate descriptive statistics;
- filter engineering data using logical conditions;
- create clear engineering plots;
- perform simple polynomial curve fitting;
- estimate derivatives from measured data;
- estimate integrals from measured data;
- solve nonlinear equations numerically;
- solve systems of linear equations;
- interpret numerical results in an engineering context.
