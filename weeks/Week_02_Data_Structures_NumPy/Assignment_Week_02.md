# Week 2 Assignment — Data Structures and NumPy

## Submission
Submit one `.ipynb` or `.py` file containing code, output, and short explanations.

## Part A — Berkeley-aligned practice
1. Create variables x=10 and y=3 and calculate several arithmetic expressions.
2. Convert the string "123.45" to a floating-point number and verify the types.
3. Compare uppercase and lowercase strings using string methods.
4. Split a sentence into words and extract the final word.
5. Insert, append, and sort values in a list.
6. Create a tuple containing a label and a numerical value; access both elements.
7. Use a set to remove duplicates from a sequence.
8. Compute union, intersection, and difference for two sets.
9. Create a dictionary with at least four key/value pairs and test for a key.
10. Create NumPy arrays and perform elementwise +, −, ×, ÷, and exponentiation.
11. Create 100 evenly spaced values from −10 to 10.
12. Use Boolean indexing to select only positive values.
13. Create a 3×3 matrix and calculate its transpose.
14. Create a 2×4 zero matrix and replace the second column with ones.

## Part B — Engineering problems
15. Store five temperature measurements and report mean, min, max, and range.
16. Create voltage and current arrays and calculate elementwise electrical power.
17. Create x- and y-velocity component arrays and calculate speed.
18. Create a dictionary of material densities and calculate mass for a shared volume.
19. Use a set to find unique equipment IDs from repeated inspection records.
20. Create a 4×3 sensor matrix and calculate each sensor's mean.
21. Use Boolean indexing to find all pressure values above 500 kPa.
22. Convert a NumPy temperature array from °C to °F.
23. Slice a 20-element measurement array to obtain first five, last five, and every other measurement.
24. Explain when an engineer should prefer a list, tuple, set, dictionary, or NumPy array.
