# Week 4 — Branching and Engineering Decision Logic

## Topics
- Boolean expressions
- Comparison operators
- Logical operators: `and`, `or`, `not`
- `if`, `elif`, and `else`
- Nested conditions
- Engineering safety and classification logic

## Berkeley reference
- Chapter 4: Branching Statements
- https://pythonnumericalmethods.studentorg.berkeley.edu/notebooks/chapter04.00-Branching-Statements.html

## Engineering examples
- Machine temperature alarm
- Battery-voltage classification
- Pressure-vessel safety check
- Structural load check
- Flow-direction determination
- Motor-efficiency classification

## Learning outcomes
Students should be able to translate engineering decision rules into correct Python conditional statements.
