# Week 8 — Classification for Engineering Decisions

## Topics
- Categorical target variables
- Binary and multiclass classification
- Logistic regression
- K-nearest neighbors
- Confusion matrix
- Accuracy
- Precision
- Recall
- F1 score

## Engineering examples
- Normal vs. faulty machine
- Safe vs. unsafe operating condition
- Material class prediction
- Equipment failure classification
- Sensor-state classification

## Important question
Accuracy alone may be misleading. In an engineering safety problem, discuss whether false negatives or false positives are more costly.

## Learning outcomes
Students should be able to train a classifier and interpret a confusion matrix and major classification metrics.
