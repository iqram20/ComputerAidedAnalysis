## 📘 Course Description
ESC 113 is a **MATLAB-based course in computer-aided engineering analysis**. The primary course environment is **MATLAB Live Editor**, which combines explanatory text, equations, executable code sections, outputs, tables, and plots in a notebook-style workflow.

Students learn programming and computational methods through engineering applications. Topics include variables, vectors and matrices, functions, branching, iteration, data analysis, visualization, machine learning, numerical methods, deep learning and AI concepts, and engineering simulation.

Course lectures are organized as:

**engineering concept → short explanation → small MATLAB code section → output/figure → engineering interpretation → next step**

Students are expected to run one Live Editor section at a time, inspect the result, and determine whether the output is mathematically and physically reasonable before continuing.

Python materials from earlier versions of the course are archived for reference and are not part of the active weekly course sequence.

## 🎯 Learning Outcomes
By the end of the course, students will be able to:
1. Write clear MATLAB programs for engineering analysis.  
2. Use arrays, functions, branching, iteration, visualization, and file/data operations to solve engineering problems.  
3. Analyze real engineering datasets using descriptive statistics and computational tools.  
4. Prepare data and build regression and classification models for engineering applications.  
5. Evaluate machine-learning models using appropriate metrics and interpret model errors and feature importance.  
6. Apply MATLAB to curve fitting, numerical differentiation, integration, nonlinear equations, and linear systems.  
7. Explain the basic principles and engineering applications of deep learning, NLP, transformers, and LLMs.  
8. Identify hallucination, privacy, safety, and validation concerns when applying generative AI in engineering.  
9. Develop simple dynamic engineering simulations from governing equations and perform parameter/sensitivity studies.  
10. Verify, validate, interpret, and communicate computational results with appropriate engineering judgment.
