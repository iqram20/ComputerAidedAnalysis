# ESC 113: Computer Aided Analysis for Engineering

**Professor:** Iqram Hussain, PhD  
Course repository: https://github.com/iqram20/ComputerAidedAnalysis

## Course Description

ESC 113 is a **MATLAB-based engineering computing course**. The primary programming environment is **MATLAB Live Editor**, where lecture material is organized like an executable notebook: short explanation, small code section, output or figure, engineering interpretation, and the next step.

Students use MATLAB to solve engineering problems involving calculations, vectors and matrices, functions, branching, iteration, data analysis, visualization, machine learning, numerical methods, artificial intelligence, and simulation.

The emphasis is on understanding the engineering problem and computational method rather than memorizing syntax. Students should be able to read a governing equation, translate it into MATLAB, run the calculation, inspect the result, and decide whether the output is physically and numerically reasonable.

### Standard Lecture Workflow

Each lecture follows this pattern:

1. engineering concept or question;
2. governing equation or computational objective;
3. short explanation;
4. small MATLAB code section;
5. visible output, table, or figure;
6. interpretation of the result;
7. next computational step;
8. guided exercise.

In Live Editor, students should run one section at a time and inspect the result before continuing.
